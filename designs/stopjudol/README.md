# STOPJUDOL — 10 screenshot App Store

Ukuran PNG: **1290 × 2796 px**. Set mengikuti urutan gambar 01–10.

## Import dan edit

1. Buka editor dan pilih **JSON Manual**. AI Chat tetap tersedia di tab sebelahnya.
2. Upload `project.json`, atau paste isinya ke kolom config.
3. Pilih seluruh PNG dalam folder `assets/`, urutkan 01–10. Index gambar dimulai dari 0.
4. Klik **Validasi**, lalu **Terapkan**. Seluruh set mengganti proyek sebagai satu operasi Undo.
5. Pindah ke **Visual** untuk edit manual, atau **AI Chat** untuk meminta perubahan.
6. Klik **Download semua** untuk export ulang.

Folder `png/` berisi sepuluh desain jadi. Gambar dalam `assets/` adalah original tanpa kompresi atau perubahan. JSON memakai font Nunito, frame iPhone 14 Pro Dark, screenshot contain, dan preset app67. Semua warna dan posisi dapat diedit.

Setiap slide memakai satu lingkaran transparan dan tiga sparkle kecil di ruang kosong, tanpa menutupi copy atau UI. `preview.png` menampilkan seluruh set; urutannya 01–05 pada baris atas dan 06–10 pada baris bawah.
